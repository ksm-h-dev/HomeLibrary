Домашний библиотекарь

Версия 1.0.0

Веб-приложение для управления электронной библиотекой. Позволяет каталогизировать книги, искать по названию и автору, управлять хранилищами на разных носителях (HDD, SSD, DVD, NAS).

Возможности

  • Полнотекстовый поиск по названию, автору, описанию
  • Поддержка PDF, DJVU, EPUB, FB2, RAR, ZIP
  • Управление несколькими хранилищами
  • Автоопределение подключенных дисков
  • Идентификация носителей по метке тома или catalog.json
  • Обложки книг и метаданные
  • Фильтрация по формату, категории, году

Технологии

FastAPI • SQLite + FTS5 • Vue.js-like SPA
