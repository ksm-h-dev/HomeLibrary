# Домашний библиотекарь

Веб-приложение для каталогизации и поиска электронной библиотеки с доступом через локальную сеть.

## Возможности

- Автоматический импорт книг из файловой системы
- Полнотекстовый поиск по названию, автору и описанию
- Категоризация и тегирование книг
- **Управление несколькими хранилищами** (HDD, SSD, DVD, NAS, сетевые папки)
- **Идентификация носителей** (catalog.json или метка тома)
- **Обновление при повторном сканировании** (все поля)
- **Автоопределение подключенных дисков**
- Веб-интерфейс для просмотра каталога
- **Унифицированный поиск и фильтрация** (Поиск/Фильтр/Сортировка/Сброс)
- **Сортировка** по дате, названию, автору, году, страницам
- **Фильтрация** по формату, категории, году, хранилищу
- Доступ к библиотеке через браузер в локальной сети

## Требования

- Python 3.11+
- Windows или Linux
- Браузер для доступа к веб-интерфейсу

## Быстрый старт

### 1. Импорт библиотеки

```bash
python -m app.services.importer
```

Эта команда сканирует каталог `C:\Book\` и импортирует все книги в базу данных.

### 2. Запуск сервера

```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

### 3. Доступ к библиотеке

- **Локально:** http://localhost:8000
- **В сети:** http://ИМЯ_КОМПЬЮТЕРА:8000

## Конфигурация

Настройки хранятся в файле `config.py`:

```python
BOOKS_DIR = "C:/Book/"           # Каталог с книгами
DATABASE_URL = "library.db"     # Путь к базе данных
SERVER_HOST = "0.0.0.0"         # Хост для прослушивания
SERVER_PORT = 8000               # Порт сервера
```

## API Endpoints

| Метод | Endpoint | Описание |
|-------|----------|----------|
| GET | `/` | Веб-интерфейс |
| GET | `/api/books` | Список всех книг |
| GET | `/api/books/{id}` | Информация о книге |
| GET | `/api/search` | Полнотекстовый поиск |
| GET | `/api/categories` | Список категорий |
| GET | `/api/stats` | Статистика библиотеки |
| GET | `/api/sources` | Список хранилищ |
| POST | `/api/sources` | Добавить хранилище |
| DELETE | `/api/sources/{id}` | Удалить хранилище |
| POST | `/api/sources/{id}/scan` | Сканировать хранилище |
| GET | `/api/sources/discover` | Автоопределение дисков |

### Параметры /api/books

```
GET /api/books?limit=20&offset=0&category=Programming&format=pdf&year=2020&source_id=1&sort_by=title
```

- `limit` - количество результатов (по умолчанию 20)
- `offset` - смещение для пагинации
- `category` - категория книги
- `format` - формат файла (pdf, djvu, rar, zip)
- `year` - год издания
- `source_id` - ID хранилища
- `sort_by` - сортировка: date, title, author, year, pages

### Параметры /api/search

```
GET /api/search?q=python&format=pdf&year=2020&sort_by=title
```

- `q` - поисковый запрос
- `format` - формат файла
- `category` - категория
- `year` - год издания
- `source_id` - ID хранилища
- `sort_by` - сортировка: date, title, author, pages
- `limit` - количество результатов
- `offset` - смещение

## Формат файла описания (.txt)

Система автоматически извлекает метаданные из файлов `.txt` с описанием книги:

```

URL: http://example.com/link
Размер: 3,87 MB (3872237)
Дата: 01.02.2006 17:55:09

Автор: Имя Автора

Издательство: Издательство

Год: 2004

Формат: PDF
Размер: 5.11 MB
```

## Подготовка DVD/сменных носителей

### Структура каталога на носителе

```
E:\
├── catalog.json            ← идентификатор хранилища (опционально)
├── programmy/
│   ├── book1.pdf
│   ├── book1.txt          ← метаданные
│   └── book1.jpg          ← обложка
└── psychologie/
    └── book2.djvu
```

### Файл catalog.json (рекомендуется)

Создайте файл `catalog.json` в корне носителя для уникальной идентификации:

```json
{
  "id": "DVD-PROG-001",
  "name": "DVD Программирование 2024",
  "version": "1.0",
  "created": "2024-01-15"
}
```

**Приоритет идентификации:**
1. `catalog.json` → `id` (самый надёжный)
2. Метка тома (volume label) диска
3. Fallback: путь к файлу

### Поведение при повторном сканировании

- Если книга с тем же `source_id + relative_path` существует → **обновляются ВСЕ поля** (метаданные, обложка)
- При смене буквы диска (E:\ → F:\) книги корректно перепривязываются по `catalog_id` или `volume_label`

## Запуск как системная служба (Windows)

Для автоматического запуска при старте системы:

```bash
pip install pywin32
```

Создайте scheduled task или используйте NSSM.

## Развертывание в локальной сети

1. Убедитесь, что файрвол разрешает входящие соединения на порт 8000
2. Запустите сервер с `host = "0.0.0.0"`
3. Другие компьютеры в сети могут получить доступ по IP или имени компьютера
