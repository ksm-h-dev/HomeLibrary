# Домашний библиотекарь

Веб-приложение для каталогизации и поиска электронной библиотеки с доступом через локальную сеть.

## Возможности

- Автоматический импорт книг из файловой системы
- Полнотекстовый поиск по названию, автору и описанию (FTS5)
- Категоризация и тегирование книг
- **Управление несколькими хранилищами** (HDD, SSD, DVD, NAS, сетевые папки)
- **Идентификация носителей** (catalog.json или метка тома)
- **Подтверждение наличия** - при сканировании книги подтверждаются без перезаписи данных
- **Новые поступления** - флаг `is_new_arrival` (сбрасывается через 7 дней)
- **Фильтрация по наличию** - доступно/отсутствует/новые поступления
- **Цветовая индикация** - зелёный (в наличии), красный (отсутствует)
- **Автоопределение подключенных дисков**
- Веб-интерфейс для просмотра каталога
- **Унифицированный поиск и фильтрация** (Поиск/Фильтр/Сортировка/Сброс)
- **Сортировка** по дате, названию, автору, году, страницам
- **Фильтрация** по формату, категории, году, хранилищу, наличию
- **Экспорт метаданных** в .json при редактировании книги
- **Перемещение файлов** книги (книга + txt/json + обложка)
- **Приоритет .json** метаданных над .txt при импорте
- **Расширенные форматы обложек** (bmp, webp, tiff)
- **Аудит-логи** - отслеживание действий пользователя
- **Прогресс-трекер** - SSE-события для сканирования без дублирования
- **Кастомные модальные окна** - замена alert()/confirm() на единый стиль
- **Перевод сообщений** - API возвращает сообщения на русском языке
- **Исправление статистики сканирования** - корректный подсчет imported/confirmed/covers_found
- Доступ к библиотеке через браузер в локальной сети

## Требования

- Python 3.11+
- Windows или Linux
- Браузер для доступа к веб-интерфейсу

## Установка

### 1. Клонирование или копирование проекта


## Быстрый старт

### 1. Импорт библиотеки

```bash
python -m app.services.importer
```

Эта команда сканирует каталог `C:\Book\` и импортирует все книги в базу данных.

### 2. Запуск сервера

```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

### 3. Доступ к библиотеке

- **Локально:** http://localhost:8000
- **В сети:** http://ИМЯ_КОМПЬЮТЕРА:8000

## Конфигурация

Настройки хранятся в файле `config.py`:

```python
BOOKS_DIR = "C:/Book/"           # Каталог с книгами
DATABASE_URL = "library.db"     # Путь к базе данных
SERVER_HOST = "0.0.0.0"         # Хост для прослушивания
SERVER_PORT = 8000               # Порт сервера
```

### Параметры /api/books

```
GET /api/books?limit=20&offset=0&category=Programming&format=pdf&year=2020&source_id=1&sort_by=title&availability=new
```

- `limit` - количество результатов (по умолчанию 20)
- `offset` - смещение для пагинации
- `category` - категория книги (фильтр по последней части пути, например `Книги/English` → ищет `English`)
- `format` - формат файла (pdf, djvu, rar, zip)
- `year` - год издания
- `source_id` - ID хранилища
- `sort_by` - сортировка: date, title, author, year, pages
- `availability` - фильтр по наличию: `available`, `missing`, `new`

### Параметры /api/search

```
GET /api/search?q=python&format=pdf&year=2020&sort_by=title&availability=new
```

- `q` - поисковый запрос
- `format` - формат файла
- `category` - категория
- `year` - год издания
- `source_id` - ID хранилища
- `sort_by` - сортировка: date, title, author, pages
- `limit` - количество результатов
- `offset` - смещение
- `availability` - фильтр по наличию: `available`, `missing`, `new`

## Формат метаданных (.txt / .json)

Система автоматически извлекает метаданные из файлов `.txt` или `.json` с описанием книги:

### Приоритет: .json → .txt

**`.json` (рекомендуется):**
```json
{
  "author": "Автор",
  "title": "Название книги",
  "publisher": "Издательство",
  "isbn": "5-94057-183-2",
  "year": 2004,
  "pages": 192,
  "description": "Описание книги..."
}
```

**`.txt` (устаревший формат):**

```
Файл: название_книги.rar
URL: http://example.com/link
Размер: 3,87 MB (3872237)
Дата: 01.02.2006 17:55:09
Описание:
Автор: Имя Автора
Название: Название книги
Издательство: Издательство
ISBN: 5-94057-183-2
Год: 2004
Страниц: 192
Формат: PDF
Размер: 5.11 MB
```

## Подготовка DVD/сменных носителей

### Структура каталога на носителе

```
E:\
├── catalog.json            ← идентификатор хранилища (опционально)
├── programmy/
│   ├── book1.pdf
│   ├── book1.txt          ← метаданные
│   └── book1.jpg          ← обложка
└── psychologie/
    └── book2.djvu
```

### Файл catalog.json (рекомендуется)

Создайте файл `catalog.json` в корне носителя для уникальной идентификации:

```json
{
  "id": "DVD-PROG-001",
  "name": "DVD Программирование 2024",
  "version": "1.0",
  "created": "2024-01-15"
}
```

**Приоритет идентификации:**
1. `catalog.json` → `id` (самый надёжный)
2. Метка тома (volume label) диска
3. Fallback: путь к файлу

### Поведение при сканировании

**Логика сканирования:**
- Существующие книги: подтверждение наличия (обновление `is_available`, `last_seen`) без перезаписи данных
- Новые книги: добавление с флагом `is_new_arrival = 1`
- Отсутствующие книги: пометка `is_available = 0` (красный цвет карточки)
- Флаг "Новое поступление" сбрасывается через 7 дней после подтверждения

**Идентификация хранилища:**
1. `catalog.json` → `id` (самый надёжный)
2. Метка тома (volume label) диска
3. Fallback: путь к файлу

## Запуск как системная служба (Windows)

Для автоматического запуска при старте системы:

```bash
pip install pywin32
```

Создайте scheduled task или используйте NSSM.

## Развертывание в локальной сети

1. Убедитесь, что файрвол разрешает входящие соединения на порт 8000
2. Запустите сервер с `host = "0.0.0.0"`
3. Другие компьютеры в сети могут получить доступ по IP или имени компьютера
